# re-run `pip install` when this file's contents change, so an editable
# install of the local package can end up pinned to a stale build while
# app.py itself (read fresh from git on every run) moves ahead - a
# mismatch that surfaces as ImportError for anything added after that
# stale install. satsub/app.py instead inserts the repo root onto
# sys.path directly at import time, which always reflects the current
# checkout with no separate install step and nothing to go stale.
